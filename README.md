# Ghost Node Field Simulator

A browser-based prototype for a battery-less agricultural sensor node. It simulates soil moisture, microclimate, crop health, ambient energy harvesting, supercapacitor charge, adaptive sampling, and irrigation alerts.

All displayed values are illustrative simulation data and are not live hardware telemetry.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

The repository includes an Actions workflow that deploys this static page to GitHub Pages whenever changes are pushed to `main`. In repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if Pages has not already been enabled. The public site will be available at `https://arunodhayen-23.github.io/ghost-node/` once the first workflow deployment succeeds.
